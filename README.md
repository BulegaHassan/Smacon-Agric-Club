# GreenHarvest — student website project

A beginner-friendly, responsive four-page website made with HTML, CSS, Bootstrap 5 and a small amount of JavaScript.

## Pages
- `index.html` — landing page
- `products.html` — agricultural produce catalogue
- `team.html` — project team and roles
- `contact.html` — contact information and demo enquiry form
- `css/style.css` — shared design styles
- `js/script.js` — copyright year and email-draft form behaviour

## Run the website
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or install the **Live Server** extension in VS Code and select **Open with Live Server**.
4. Internet access is required for the Bootstrap CDN and the sample photographs.

## Before publishing
- Replace GreenHarvest with the actual school/group name.
- Replace sample contact information with school-approved details.
- Verify product descriptions, stock and prices with the agriculture group.
- Replace the placeholder recipient email in `js/script.js`.
- Get permission before publishing learners' names or photographs.
- Check every image and link and test on a phone.
- The demo form does not save submissions or send email directly; it opens the visitor's email application after a real email address is configured.
- This website has no inventory database, payment system or order management.

## Suggested teaching order
1. Explain file structure and basic HTML.
2. Build one simple page with headings, paragraphs, images and links.
3. Add the navigation bar and footer to every page.
4. Introduce Bootstrap containers, rows, columns, cards and buttons.
5. Add the shared CSS theme.
6. Build the products, team and contact pages.
7. Explain the small JavaScript file and test the form behaviour.
8. Test links, image alt text, keyboard navigation and small-screen layout.
9. Ask each learner to explain and change one part of the site.
